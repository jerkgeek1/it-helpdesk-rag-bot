# Software and admin rights

## Installing approved software
Software Center lists pre-approved applications such as Chrome, Firefox, VS Code, Zoom, Docker Desktop, Python and Node.js. Install them from there at any time without asking for permission.

## Requesting new software
If an application is not in Software Center, open a Software Request in the Service Portal. Your manager must approve it, and the security team reviews it. The review takes up to 5 business days. Paid tools also need a budget code from your manager.

## Admin rights
Employees do not have permanent administrator rights on their laptops. When an installer needs admin access, use the Elevate tool, which grants administrator rights for 30 minutes and logs what you do.

## Prohibited software
Torrent clients, unapproved VPN apps and cryptocurrency miners are not allowed on company devices. They are removed automatically and the security team is notified.
