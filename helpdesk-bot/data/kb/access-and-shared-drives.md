# Access requests and shared drives

## Requesting access to a shared drive
Shared drives live in SharePoint. Request access in the Service Portal under Access Request. The data owner approves the request, usually within 2 business days. Access is reviewed every quarter and unused access is removed.

## GitHub and engineering tools
Engineers get GitHub organisation access through the Access Request form under Engineering. Your manager approves it and access is normally granted the same day.

## Production access
Access to production systems needs approval from both your manager and the security team. It is granted just in time and expires after 30 days, after which you must request it again.

## Contractor accounts
Contractor accounts expire automatically on the contract end date and never last longer than 6 months. To extend one, the sponsoring manager submits a renewal request before it expires.
